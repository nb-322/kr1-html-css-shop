# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров с фильтрами;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — скрипт модального окна и формы;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов `--space-*`;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- подсветка ошибочных полей через `[aria-invalid="true"]`;
- файл `css/style.css` разделён на смысловые блоки.

## БЭМ и позиционирование

Классы названы по методологии БЭМ: блок, элемент через `__`, модификатор через `--`.
Основные блоки: `site-header`, `site-nav`, `hero`, `advantages`, `products`,
`product-card`, `about`, `site-footer`, `contacts`, `order-dialog`, `order-form`,
`button`, `scroll-top`.

Позиционирование:

- `position: relative` у карточки товара как контейнера;
- `position: absolute` у бейджа «Хит» внутри карточки;
- `position: fixed` у шапки сайта и кнопки «Наверх»;
- `z-index` вынесен в переменные `--z-badge` и `--z-scroll-top`.

## Навигация

- единое меню в шапке на всех страницах;
- переходы между `index.html`, `catalog.html` и `contacts.html`;
- якорные ссылки на разделы главной страницы: `#advantages`, `#popular`, `#contacts`;
- хлебные крошки на внутренних страницах;
- плавная прокрутка через `scroll-behavior: smooth`;
- подсветка раздела, к которому выполнен переход, через `:target`.

## Использование Flexbox и Grid

- Flexbox: шапка сайта, основное меню, внутренняя структура карточки товара, кнопки формы.
- CSS Grid: сетка карточек товаров (`products-grid`), раскладка страницы каталога «фильтры + товары» (`catalog-layout`, именованные области), форма фильтров.

## БЭМ-структура проекта

Блоки проекта:

- `site-header` — шапка сайта (`__inner`, `__logo`);
- `site-nav` — основная навигация (`__list`, `__item`, `__link`, `__link--active`);
- `breadcrumbs` — хлебные крошки (`__link`, `__current`);
- `page` — контейнер основного содержимого;
- `hero` — первый экран главной страницы;
- `advantages`, `products`, `catalog`, `contacts-info`, `feedback`, `about` — смысловые разделы страниц;
- `products-grid` — сетка карточек товаров;
- `product-card` — карточка товара (`__badge`, `__title`, `__description`, `__price`, `__button`, модификаторы `--featured`, `--discount`, `--new`, `--recommended`, `--out-of-stock`);
- `catalog-layout` — раскладка страницы каталога;
- `catalog-filters` — фильтры каталога (`__form`, `__group`, `__legend`, `__option`, `__label`, `__input`);
- `catalog-products` — список товаров каталога;
- `order-dialog` — модальное окно заявки (`__title`);
- `order-form` — форма заявки (`__field`, `__label`, `__input`, `__select`, `__textarea`, `__hint`, `__actions`);
- `button` — кнопка (`--primary`, `--secondary`, `--disabled`);
- `success-message` — сообщение об успешной отправке;
- `scroll-top` — фиксированная кнопка «Наверх»;
- `site-footer` — подвал сайта (`__title`, `__text`);
- `contacts` — список контактов (`__item`, `__link`).

Стилизация выполняется только через классы: `id` используются для якорей и JavaScript, inline-стилей в проекте нет.

## Что реализовано по КР №1

- пять связанных страниц с единой навигацией и якорными ссылками;
- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- хлебные крошки на внутренних страницах, уникальные `title` и `meta description`;
- карточки товаров с пятью модификаторами, бейджи через `position: absolute`;
- таблица характеристик с `caption`, `thead`, `tbody`, `th`, `td`;
- форма заявки на отдельной странице и в модальном окне `dialog`, базовая HTML-валидация и подсветка ошибок;
- CSS-переменные в `:root`, состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox: шапка, меню, карточка товара, кнопки формы;
- CSS Grid: сетка товаров, раскладка каталога «фильтры + товары», страница товара;
- позиционирование: `relative`, `absolute`, `fixed` (закреплённая шапка и кнопка «Наверх»), `z-index` в переменных;
- БЭМ-именование классов, стилизация только через классы.

## Самостоятельные доработки

- расширенный каталог на шесть товаров и отдельная страница товара с таблицей характеристик;
- рабочие фильтры каталога на JavaScript: фильтрация по категории и цене без перезагрузки, счётчик найденного и сброс;
- фиксированная кнопка «Наверх» и подсветка раздела при переходе по якорю (`:target`);
- пять вариантов карточки через БЭМ-модификаторы: хит, скидка, новинка, выбор редакции и товар не в наличии (у последнего отключена кнопка через `button--disabled`);
- страница заявки с выбором товара, которая использует ту же валидацию, что и модальное окно;
- доступность: видимый фокус, `aria-label` у навигации, `aria-invalid` на ошибочных полях, подписи ко всем полям формы;
- контактный блок в подвале на всех страницах и собственное векторное изображение товара.
